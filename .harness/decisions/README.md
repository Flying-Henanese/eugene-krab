# Decisions

Use this directory for architecture decision records and design indexes that should remain visible to future agents.

Existing design docs currently live under `docs/superpowers/specs/`:

- `docs/superpowers/specs/2026-07-01-feishu-wsclient-design.md`
- `docs/superpowers/specs/2026-07-02-tushare-tavily-stock-analysis-design.md`

Do not duplicate those files here. Distill still-current behavior into `context/`; link to the original specs only for rationale, scope history, or ADR follow-up.

For new ADRs, use a concise format:

- Context
- Decision
- Alternatives considered
- Consequences
- Verification or follow-up
